科技与装备显示重做（2026-10-01）
================================

上轮错误
--------
上轮把原版科技解锁的原版装备 ID 也映射到幻想乡名称、说明和图片上。
因此原版步枪、坦克和飞机在幻想乡国家下也显示成了幻想乡装备，范围错误。
此外，早期生成器还给原版可设计底盘添加了幻想乡名称。
这些显示覆盖已经全部撤回。

当前规则
--------
1. 原版武器、坦克、飞机、可设计底盘：使用原版自己的名称、说明、图标和定义。
2. 幻想乡型号：保留原型号 ID、原中文名称、说明、图标和数值，归入原版装备原型。
3. 原版兵种通过同一原型使用原版装备和幻想乡型号；两者的型号 ID、显示资源各自对应。
4. 科技研究继续使用原版科技 ID，对应幻想乡科技名称/图片只用于研究节点。
   不把研究节点的幻想乡名称或图片复制到其解锁的原版装备上。
5. 科技 ID 与原版装备原型 ID 同名时，保留原版显示；例如 super_heavy_tank_chassis。
6. 所有 145 个幻想乡保留/派生型号都有直接图标引用，不依赖已经删除的旧自定义原型。

示例
----
infantry_equipment_1：原版步枪型号，保持原版名称、说明和图片。
touhou_magic_infantry_equipment_1：繁彩魔力发射器，使用原幻想乡名称、图片和数值；
两者同属 infantry_equipment，供原版 infantry 营使用。

light_tank_chassis_1、small_plane_airframe_1：原版装备型号，保持原版显示。
touhou_magic_light_tank_equipment_1、touhou_magic_fighter_equipment_1：保留原幻想乡显示和数值。
幻想乡装甲和航空特色体现在这些型号自身，原版底盘不再被改名改图。

校验
----
241 个脚本/UI 文件通过解析；0 项静态错误。
原版装备定义覆盖：0。
原版装备名称/说明覆盖：0。
原版装备图标覆盖：0。
1,813 个国家科技映射、145 个型号图标和 4,278 个图形引用有效。
2,108 项原幻想乡装备明确数值保持一致。

保护检查以本机原版装备 ID 为依据，包含原版复制规则生成的角色原型和型号。
检查整个 Mod 的装备定义、中文本地化和图标，防止以后再次改写原版装备显示。
后续国家解锁调整已实机完成加载及 1936 年历史初始化，本项目加载错误为 0。
没有目视核对科技/生产界面；重启后新映射生效。

国家解锁调整
------------
原版科技的装备和模块解锁列表恢复原版，662 份列表对照均一致。
幻想乡国家脚本按原科技、制造体系和项目条件登记对应型号，生产条件另要求本国登记旗标。
142 个成品型号通过国家设计效果登记一次，原数值不变；
三个星莲船型号保留空船体设计器，通过项目登记开放船体，不强制生成缺少模块的设计。
星莲船底盘供引擎预建基础框架，生产/设计条件仍限制国家和项目；原版装备没有改动。
11 个条件场景通过；条件检查不模拟生产界面和战斗。
