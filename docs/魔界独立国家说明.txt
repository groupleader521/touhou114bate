魔界独立国家
============
敌对魔界使用新 TAG MKI，名称“魔界”，领袖为神绮。
原 KTL 占位定义保留；敌对入侵不再接管南非或随机原版国家。

地图与入口
----------
新开局不改变地区归属。正式邀请选择启动挑战后，仅将地区 681 的所有权和控制权交给 MKI，并设为首都；原所有国保留自己的 TAG、领导人和其他领土。
正式入口随后进入 360 天准备期；调试“召唤魔界”使用相同的国家创建流程，直接进入主的降临，不预约第二次降临。
三语国家名称、神绮名称以及标准/中/小三种尺寸国旗已配置。国旗沿用现有魔界素材。

领导人与生命周期
----------------
MKI 国家历史正式招募 TOUHOU_boss_shinki_leader，并设置法西斯执政；运行时补齐缺失角色或领袖身份，校正神绮姓名和肖像后晋升。
重复调用不会生成额外同名角色。原有其他调试入口仍可调用通用 Boss 领袖效果。
邀请和召唤共用防重复条件；已召唤、已结束、MKI 已存在或爱丽丝主动魔界路线已启动时不再创建。
第一至最终阶段限定 MKI，检查国家存续与阶段标记；旧南非宿主不会继续执行这些阶段。
独立国家补充基础步兵、卡车和支援等科技，不依赖南非的历史科技。现有 Boss 数值和部队规模维持原设计。

维护与校验
----------
node tools/check_makai_country.cjs
node tools/check_boss_character_setup.cjs
node tools/validate_military_migration.cjs
tools/makai_country_setup.cjs 和 tools/boss_character_setup.cjs 同时接入军事生成器，避免后续重建回到旧入口或旧领袖逻辑。
修改前入口和受管文件的备份在 F:/Hoi4/touhou/backups/makai_country，保留项目相对路径。

验证边界
--------
已完成脚本解析、国家定义/本地化/旗帜、正常与调试路径、重复召唤、原版国家隔离、阶段条件与领袖修复的静态校验。
本次未进行游戏引擎及界面实测。加载新增 TAG 后应重启游戏，并以新开局验收；不承诺把旧存档中已经转为魔界的南非自动恢复或迁移。
此前发现的 BE/GE 战后收尾和救赎军停用事件不在本次修改范围内。
