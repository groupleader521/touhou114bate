原版底盘隔离与历史设计修复说明
============================
2026-10-02
后续改造已撤掉原版科技覆盖，当前研究同步和研究加成规则见《独立研发与减少原版覆盖改造说明.txt》。

用户反馈
--------
基础型中型坦克显示幻想乡人物图片。
中国已研究 1938 基础中型、1940 改进中型等底盘科技，生产菜单却只列出战间期轻型底盘。
这一科研与生产列表不对应的问题，不能由空底盘缺少主要武器来解释。

显示隔离
--------
引擎会把共用科技 Sprite 作为原版底盘/机体的图片后备入口。
此前保护只检查装备同名 Sprite，没有覆盖 GFX_<国家>_<科技 ID>_medium。
对 90 个共用科技显示键进行隔离，取消 633 项幻想乡国家科技图片别名。
这些共用坦克/飞机科技恢复使用原版图案；幻想乡专用型号保留自己的完整图片和模块图标。
科技的国家文字别名保留，但不再通过图案后备入口污染原版型号。

激活与升级链隔离
----------------
23 个幻想乡底盘与 47 个幻想乡机体全部 active = no，由本国研究许可的 enable_equipments 激活。
此前 active = yes 会让它们在研究与国家筛选前就成为全局激活型号，存在影响原版型号选择和过时判定的风险。
六个附灵底盘和十个大型通用机体不再 parent 到原版型号。
附灵和通用大型系列的升级链只连接自己的前一等级，其他系列保持独立。
原版坦克/飞机定义、原版科技解锁清单和原版国家历史不改写。

空底盘与完整设计
----------------
原版 light_tank_chassis 的 default_modules.main_armament_slot 本来就是 empty。
科技解锁空底盘并不等于已经保存一辆可以生产的完整坦克。
第三张图的缺少主要武器红字仅解释现有战间期轻型底盘不能直接生产，不能解释已研究的中型和其他底盘为何未列出。
这些已研究底盘至少应该提供进入设计器的入口，完整设计保存后才是可生产的成品。
原版中国初始 infantry_weapons、gw_artillery 和 gwtank_chassis 可以解锁所需基础模块。
检查验证了原版轻型底盘加重机枪、原版炮塔/悬挂/装甲/引擎可以形成完整的必要槽位装配。
原版国家不授予幻想乡许可，也不自动赠送额外坦克科技或新编完整坦克设计。
是否正常显示所有已研究底盘和已保存设计，仍需本轮游戏内界面复核。

历史库存修复
------------
实际日志另外报告 ALI 部队引用的上海级 version 1 设计不存在。
为幻想乡国家初始化其起始陆军文件确实引用的装甲设计，处理方式与历史空军设计一致。
历史设计允许在部件未研究时存在，但不授予配件许可、不跳过科研门槛。
2026-10-02 后续实际日志发现仅设置 allow_without_tech 无法创建未激活的底盘设计。
现已分开底盘与部件许可，在创建历史设计前授权其专用底盘，并补回 EVI 的妖精装甲；详见《历史装甲报错修复说明.txt》。
这样可以保留已有部队与库存的设计引用，避免因新加基础研究条件而漏建历史设计。

验证与边界
----------
42 项国家与定义检查通过，包括独立每日同步、原版科技不覆盖、中国已研究轻型、中型、重型 1/2 级的原版解锁与升级链、专用许可不占用原版解锁、全球激活/升级链/后备图标隔离及全部国家历史设计创建前的底盘激活检查。
1,104 项原版科技装备/模块解锁字段与本机游戏保持完整比较通过，原版科技源文件和定义覆盖均为 0。
2,108 项原装备数值校验通过；535 个模块、99 个预设、229 张图案的保护检查通过。
坦克和飞机的配件类别隔离检查继续通过。
这些是配置和脚本检查，不是生产列表的引擎复现。不能据此宣布已研究中型底盘的消失问题已解决。
此前已移除幻想乡型号的全局激活和原版 parent 链，需重启加载后复核同一科研状态下的生产列表。

实现
----
military_presentation.cjs：共用科技图标后备入口隔离。
armor_designer.cjs / aircraft_designer.cjs / aircraft_module_isolation.cjs：本国许可激活与独立升级链。
migrate_military_system.cjs：初始化起始陆军引用的历史装甲设计。
validate_military_migration.cjs / check_country_equipment_conditions.cjs：实际定义、国家条件和历史初始化检查。
